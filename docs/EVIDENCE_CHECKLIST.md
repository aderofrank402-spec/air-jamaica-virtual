# Portfolio evidence checklist

The next portfolio pass will add live-system screenshots and verified operational totals. Capture each image at desktop width, use the same browser theme where possible, and redact personal or sensitive data before sharing.

## Required screenshots

### 1. Operations overview — added

Capture the dashboard area that shows total completed flights, flight hours, distance, pilots, or another high-level operational summary.

**Published evidence:** 274 completed flights, 11 active pilots, and 273 global destinations, captured 2 November 2026.

**Redact:** names, email addresses, account IDs, private notices, financial values not intended for publication.

### 2. Destinations or route network

Capture a route map, destination directory, or schedule view that visibly demonstrates network breadth.

**Include if visible:** destination count, airport codes, map markers, or route totals.

### 3. Live operations

Capture the live map or active-flight status view. It is acceptable if no flight is active, provided the operational interface is visible.

**Redact:** pilot identity and any private tracking identifiers.

### 4. Fleet management

Capture the public fleet page or an administrative aircraft list showing types and operational status.

**Redact:** internal notes, private maintenance remarks, or identifiers that should not be public.

### 5. Pilot workflow

Capture a pilot dashboard, flight search, dispatch brief, or logbook view that shows a real end-to-end user workflow.

**Redact:** pilot name, email, account number, API keys, tokens, and private messages.

### 6. Administration

Capture one strong staff-facing screen such as pilot-report review, operations dashboard, training management, or schedule administration.

**Redact:** all personal data and any production configuration values.

## Optional video

A 60–120 second walkthrough can show the public home page, flight search, pilot dashboard, live operations, and one administrative workflow. Remove browser bookmarks, notifications, passwords, and unrelated tabs before recording.

## Evidence rules

- Do not type totals from memory; use a visible live-system source.
- Record the capture date for statistics that change over time.
- Prefer PNG at the browser's native resolution.
- Do not crop away the page context that proves what the number represents.
- Never publish credentials, tokens, personal records, private messages, or raw production exports.
